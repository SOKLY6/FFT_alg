# FFT

Реализация быстрого прямого и обратного преобразования Фурье

## Активация виртуального окружения

Прописать команду после `make build`
`. .venv/bin/activate`

## Команды Makefile

- `make build` - создание виртуального окружения и установка зависимостей
- `make start` - запуск программы

## Использование CLI

Коэффициенты полиномов вводятся через пробел, начиная со свобдного члена
Мнимая часть чисел для IFFT вводится в формате 2j, 0j, 1.5j
